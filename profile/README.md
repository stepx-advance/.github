# STEPX Advance

面向 STEPX 设备的实用工具与适配项目。

| 项目 | 简介 |
| --- | --- |
| [meizu-share](https://github.com/stepx-advance/meizu-share) | PZ261A 互传适配工具，支持 Linux、macOS 和 Windows，可选桌面与控制中心入口。 |
| [backscreen-toolbox](https://github.com/stepx-advance/backscreen-toolbox) | PZ261A 点阵背屏工具箱，提供充电、电量、满电与旁路状态显示，支持旋转过渡与设置引导。 |

各项目独立维护、独立发布。使用前请阅读相应仓库的适用范围、安装说明与版权声明。

本系列为非官方项目，没有相关设备厂商的官方认证或背书。
